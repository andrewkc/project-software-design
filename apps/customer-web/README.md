# customer-web

## Estado

Planificada y fuera del MVP documentado. La carpeta solo contiene `.gitkeep`.

## Cómo funcionará

Tienda pública para compradores. Se publicará en `bodesmart.com` y permitiría ver los productos ofertados por las bodegas, con una experiencia de compra sencilla similar a una app de delivery.

El modelo de negocio actual excluye la vista pública de compradores, los pagos, la facturación electrónica y las entregas. Por eso no hay casos de uso, endpoints ni contrato de API aprobados para esta app. No debe considerarse parte del MVP vigente.

## Comandos de instalación y arranque

No hay comandos todavía. No hay `package.json`, código fuente ni stack definido. Tampoco hay una API que esta app pueda consumir.

Cuando se apruebe su alcance, este README debe indicar:

- runtime y gestor de dependencias;
- comando de instalación;
- comando de desarrollo y URL local;
- comando de build y directorio de salida;
- endpoints públicos permitidos y variables de entorno.
