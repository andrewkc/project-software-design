# Contexto del sistema

Aplicación interna para administrador de app, jefe y empleado. No hay vista pública para compradores ni proveedor como actor. La fuente no documenta integraciones externas aprobadas. IA se describe como capacidad de apoyo, pero no se especifican proveedor, modelo ni arquitectura.

Pendiente: clientes/dispositivos, backend, persistencia, autenticación, conectividad, integraciones, despliegue, operación y monitoreo.
