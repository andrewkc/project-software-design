# Fuentes y limitaciones

Fuente primaria: README autocontenido “Entregable 1 — Modelado del negocio”, proporcionado por el equipo. Incluye entrevistas (3 respuestas), actores, nueve casos de uso y fichas, ocho entidades, diagramas Mermaid, nueve reglas y trazabilidad.

No especifica stack, arquitectura técnica, base de datos, API, proveedor/modelo IA, métricas NFR ni objetivos cuantitativos. Es una propuesta, no evidencia de implementación. Las entrevistas son exploratorias.
