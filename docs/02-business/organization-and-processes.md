# Organización y procesos

La organización objetivo es una bodega o minimarket de barrio dedicado a venta minorista de productos cotidianos, incluidos envasados y perecibles. Se usa una bodega de referencia sin atribuirle nombre comercial. La aplicación podrá registrar varias bodegas, cada una con catálogo, jefe y empleados.

Procesos cubiertos: registrar entradas de mercadería ya recibida; registrar salidas por venta o merma; consultar inventario/vencimientos; supervisar personal; definir precios/promociones; revisar sugerencias.

Problema: dificultad para mantener información organizada y actualizada sobre existencias. Las entrevistas describen controles de memoria/papel, registros de entrada con documentos o cuadernos y salidas con tickets, memoria o sin registro.

Las entrevistas son exploratorias: no demuestran reducción de pérdidas ni efectividad predictiva.
