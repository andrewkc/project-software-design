# CU-04 — Registrar entradas de mercadería

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Empleado de bodega o jefe |
| Trabajador responsable | TN-03 o TN-02 |
| Entidades relacionadas | EN-01, EN-02, EN-03, EN-04, EN-05, EN-06 |
| Reglas relacionadas | RN-02, RN-03 |

## Objetivo
Registrar entradas de mercadería.

## Flujo principal
Seleccionar productos recibidos; indicar lote, cantidad, costo unitario y vencimiento cuando corresponda; sistema valida y prepara resumen; responsable confirma; sistema guarda movimiento y detalles e incrementa cantidades.

## Flujos alternativos
Lote nuevo; vencimiento no aplicable queda vacío; cancelar sin modificar stock.

## Excepciones
Producto no registrado: debe registrarse mediante CU-02. Cantidad no positiva o datos requeridos faltantes: informar error sin guardar.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
