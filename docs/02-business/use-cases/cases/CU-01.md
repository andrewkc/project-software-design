# CU-01 — Administrar cuentas y accesos de la aplicación

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Administrador de la app |
| Trabajador responsable | TN-01 |
| Entidades relacionadas | EN-01 |
| Reglas relacionadas | RN-01 |

## Objetivo
Administrar cuentas y accesos de la aplicación.

## Flujo principal
Consultar cuentas; seleccionar crear o modificar; ingresar nombre, correo, rol y estado; el sistema valida datos requeridos; el administrador confirma; el sistema guarda y muestra resultado.

## Flujos alternativos
Desactivar cuenta; cancelar sin guardar.

## Excepciones
Datos faltantes, correo duplicado o cuenta sin permiso: informar error e impedir la modificación.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
