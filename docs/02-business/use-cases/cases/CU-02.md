# CU-02 — Gestionar los datos de la bodega y sus productos

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Jefe de bodega |
| Trabajador responsable | TN-02 |
| Entidades relacionadas | EN-01, EN-02, EN-03 |
| Reglas relacionadas | RN-02, RN-07 |

## Objetivo
Gestionar los datos de la bodega y sus productos.

## Flujo principal
Acceder a los datos de su bodega o catálogo; agregar producto o modificar información; completar datos; sistema valida; jefe confirma; sistema guarda.

## Flujos alternativos
Desactivar producto conservando historial; cancelar edición.

## Excepciones
Datos obligatorios faltantes, precio no positivo o intento de modificar otra bodega: solicitar corrección o impedir operación.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
