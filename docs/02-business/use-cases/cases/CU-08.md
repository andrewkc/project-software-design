# CU-08 — Gestionar precios, descuentos y promociones

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Jefe de bodega |
| Trabajador responsable | TN-02 |
| Entidades relacionadas | EN-01, EN-02, EN-03, EN-04, EN-07, EN-08 |
| Reglas relacionadas | RN-02, RN-06, RN-07, RN-08, RN-09 |

## Objetivo
Gestionar precios, descuentos y promociones.

## Flujo principal
Consultar sugerencias pendientes; seleccionar descuento; sistema muestra producto, existencias, precio sugerido y justificación; jefe conserva o modifica precio y define vigencia; sistema valida precio, fechas y disponibilidad; jefe confirma; sistema guarda valores aprobados, fecha y responsable y crea promoción.

## Flujos alternativos
Rechazar sugerencia; gestión manual; no hay sugerencias; cancelar antes de confirmar; desactivar promoción.

## Excepciones
Precio/fechas inválidos o falta stock apto: no guardar. Empleado intenta modificar precio o aprobar promoción: impedir.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
