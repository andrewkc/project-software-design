# CU-06 — Consultar inventario y alertas de vencimiento

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Empleado de bodega o jefe |
| Trabajador responsable | TN-03 o TN-02 |
| Entidades relacionadas | EN-01, EN-02, EN-03, EN-04 |
| Reglas relacionadas | RN-02, RN-04, RN-06 |

## Objetivo
Consultar inventario y alertas de vencimiento.

## Flujo principal
Acceder al inventario o buscar producto; sistema muestra cantidades y lotes; consultar vencimientos del periodo; sistema destaca lotes próximos a vencer y ya vencidos.

## Flujos alternativos
Lista vacía; lote sin vencimiento se muestra sin fecha estimada.

## Excepciones
Consulta de otra bodega sin permiso: impedir acceso.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
