# CU-05 — Registrar salidas por venta, vencimiento o deterioro

**Estado:** Confirmado por el Entregable 1 — Modelado del negocio.

| Campo | Valor |
|---|---|
| Actor principal | Empleado de bodega o jefe |
| Trabajador responsable | TN-03 o TN-02 |
| Entidades relacionadas | EN-01, EN-02, EN-03, EN-04, EN-05, EN-06, EN-07 |
| Reglas relacionadas | RN-02, RN-03, RN-04, RN-05, RN-06, RN-09 |

## Objetivo
Registrar salidas por venta, vencimiento o deterioro.

## Flujo principal
Seleccionar motivo, productos, lotes y cantidades; sistema comprueba cantidades positivas y stock; si es venta, verifica aptitud, aplica precios/promociones vigentes y calcula total; muestra resumen; responsable confirma; sistema revalida y guarda movimiento, detalles y responsable junto con descuento de existencias.

## Flujos alternativos
Vencimiento/deterioro se registra como merma, no venta y sin total de cobro; cancelar no guarda ni descuenta.

## Excepciones
Cantidad inválida o superior al stock; producto vencido/deteriorado; condiciones cambian antes de confirmar: informar e impedir salida parcial.

## Pendiente para especificación de software
Definir criterios de aceptación verificables, detalles de interfaz, permisos precisos, validaciones de datos y escenarios de prueba. No inferir detalles técnicos que la fuente no define.
