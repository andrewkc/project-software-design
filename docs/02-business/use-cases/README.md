# Casos de uso

| Código | Caso | Participante principal |
|---|---|---|
| CU-01 | Administrar cuentas y accesos de la aplicación | Administrador |
| CU-02 | Gestionar datos de bodega y productos | Jefe |
| CU-03 | Gestionar empleados | Jefe |
| CU-04 | Registrar entradas | Empleado o jefe |
| CU-05 | Registrar salidas por venta/vencimiento/deterioro | Empleado o jefe |
| CU-06 | Consultar inventario y alertas | Empleado o jefe |
| CU-07 | Supervisar registros de empleados | Jefe |
| CU-08 | Gestionar precios, descuentos y promociones | Jefe |
| CU-09 | Revisar y aprobar sugerencias de reposición | Jefe |

Las fichas están en `cases/`. CU-01 es administración de plataforma; CU-02…CU-09 cubren operación de bodega.
