# Requisitos no funcionales

La fuente no fija valores cuantitativos para rendimiento, disponibilidad, seguridad, compatibilidad, recuperación, escalabilidad, accesibilidad ni retención.

## Necesidades cualitativas observadas
- Facilidad de uso.
- Registro sencillo y rápido.
- La dependencia de Internet debe evaluarse: una entrevista menciona que necesitar mucho Internet sería una barrera.

## Pendiente de definir
Tiempos máximos, disponibilidad, conectividad/offline, autenticación/autorización, sesiones, auditoría, usabilidad/accesibilidad, dispositivos/navegadores, backup/restore, privacidad, retención y observabilidad. No inventar umbrales.
