# Glosario

| Término | Significado |
|---|---|
| Bodega | Establecimiento minorista objetivo. |
| Jefe de bodega | Responsable; ejecuta operaciones de empleado y gestiona/supervisa. |
| Empleado | Registra entradas/salidas y consulta existencias/vencimientos. |
| Administrador de app | Mantiene cuentas y accesos de plataforma. |
| Lote | Existencias de producto ingresadas con mismo costo y vencimiento, cuando corresponda. |
| Movimiento | Registro de entrada o salida. |
| Merma | Salida por vencimiento o deterioro, no venta. |
| Sugerencia IA | Recomendación de reposición o descuento sujeta al jefe. |
| Stock | Suma de cantidades disponibles de los lotes del producto. |
| SDD | Spec-Driven Development; desarrollo guiado por especificaciones iterativas. |
