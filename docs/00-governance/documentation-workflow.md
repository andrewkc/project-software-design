# Flujo de documentación SDD

| Etapa | Propósito | Artefacto |
|---|---|---|
| Discover | Problema, usuario y evidencia | Contexto/evidencia |
| Specify | Comportamiento esperado | `spec.md` |
| Review | Revisar ambigüedades y consistencia | Aprobación/comentarios |
| Plan | Enfoque técnico y dependencias | `plan.md` |
| Tasks | Trabajo verificable | `tasks.md` |
| Implement | Cambio de código | PR |
| Validate | Comprobar criterios | Pruebas/resultados |
| Learn | Incorporar descubrimientos | Docs/ADR/preguntas |

Aplicar por funcionalidad o cambio acotado. Las especificaciones evolucionan cuando aparecen nuevos detalles; registrar motivo y aprobación. La conversación con IA no sustituye el conocimiento validado en Git.
